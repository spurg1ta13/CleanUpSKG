# CleanUpSKG

**CleanUpSKG** is an informational cleaning services website highlighting available services and featuring an integrated blog.

🚀 **Live Demo:** [https://cleanupskg.gr](https://cleanupskg.gr)

---

## 🛠️ Technologies
- **Frontend:** React, TypeScript, Tailwind CSS, shadcn/ui
- **Build Tool:** Vite
- **AI Assisted Prototyping:** Lovable.dev
- **Hosting & Domain:** Vercel (Deployment) / Papaki.gr (Domain provider)

---

## 💻 Local Setup

```bash
# Clone repository
git clone [https://github.com/spurg1ta13/CleanUpSKG1.1.git](https://github.com/spurg1ta13/CleanUpSKG1.1.git)

# Install dependencies
npm install

# Run project
npm run dev
