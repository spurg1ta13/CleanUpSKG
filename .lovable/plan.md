
# Cleaning Services Landing Page

A professional single-page website for a cleaning business, inspired by porphyrion.eu, built in English with placeholder images.

## Sections

### 1. Top Bar & Navigation
- Contact info bar (phone, email, hours)
- Sticky navigation with logo area, menu links (Home, About, Services, Pricing, Contact), and social media icons
- Mobile-responsive hamburger menu

### 2. Hero Section
- Large hero banner with headline "Professional Cleaning Services"
- Subtitle describing comprehensive cleaning for homes, businesses, and post-construction
- Call-to-action button linking to contact section
- Decorative circular design elements in blue tones

### 3. About Us
- "Who We Are" section with company description text
- Emphasis on attention to detail, professionalism, and tailored approach

### 4. Services Overview
- Grid of 4 service cards: Residential, Post-Construction, Commercial, Specialized
- Each card with an icon and short description

### 5. Specialized Services
- Carousel/slider showcasing: Steam Disinfection, Pressure Washing, Window Cleaning
- Each with description text and placeholder image

### 6. Commercial Cleaning
- Feature section with image and description
- Three sub-cards: Office Cleaning, Restaurant Areas, Kitchen Degreasing

### 7. Post-Construction Cleaning
- Three-step process: Site Inspection → Heavy Cleaning → Final Polish
- Clean visual flow showing the process

### 8. Bio-Cleaning Section
- Description of wet-dry extraction services
- Service coverage list (upholstery, mattresses, carpets, vehicle interiors)
- Pricing table starting from specific amounts

### 9. Pricing Section
- Clean pricing cards for key services (per square meter rates, standard packages)

### 10. Contact Section
- Contact form (name, email, phone, message) — UI only
- Company contact details and business hours
- Embedded map placeholder

### 11. Footer
- Company info, quick links, social media links, copyright

## Design Style
- Primary blue color scheme (#1565C0 range) with white backgrounds
- Clean, modern, professional aesthetic
- Smooth scroll navigation between sections
- Fully responsive for mobile and desktop
